Alerts & Monitoring Limits

Configured operating thresholds

Temperature Alert

If motor temperature reaches or exceeds 60°C, the system generates a High Temperature Alert.

Limit: 60°C

Vibration Alert

If motor body vibration reaches or exceeds 0.150 g RMS, the system generates a High Vibration Alert.

Limit: 0.150 g RMS

Alert Indication

  • Red LED turns ON during an alert.
  • Buzzer turns ON during an alert.
  • Dashboard displays the alert message.
  • Normal condition is displayed when both readings are below their limits.
Note: These are initial prototype testing limits. Actual motor limits should be verified with motor specifications and project guide before practical deployment.

Project Objective

The main objective of this project is to monitor motor temperature and body vibration using ESP32 and sensors. The system provides real-time monitoring through a web dashboard and generates alerts when the configured limits are exceeded.
